# Prototipo de pantallas

Código fuente de seis pantallas de referencia visual (`.dc.html`), exportado del prototipo de Claude. Requieren el runtime de Claude para renderizarse, así que sirven sobre todo como referencia de estructura y contenido.

La fuente normativa es la especificación (`docs/specs/Sketch2CAD_MVP.md`) y el PRD. Si una pantalla del prototipo contradice el texto, manda el texto.

| Archivo | Pantalla |
|---|---|
| `Main.dc.html` | Lista de expedientes |
| `Upload.dc.html` | Carga de fuente y control de calidad |
| `Calibration.dc.html` | Calibración |
| `Editor.dc.html` | Editor 2D |
| `Review.dc.html` | Revisión y validación |
| `Export.dc.html` | Exportación y paquete |
